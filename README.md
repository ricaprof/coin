# 💱 Conversor de Moedas Premium

![Preview do Conversor](https://i.imgur.com/JQh6ZyH.png)

## ✨ Funcionalidades

- **Conversão em tempo real** com cotações atualizadas
- **Interface premium** com gradientes e animações
- **10 moedas disponíveis** incluindo Bitcoin
- **Responsividade total** para todos dispositivos
- **Histórico de conversão** integrado
- **Taxa de câmbio** em tempo real

## 🚀 Como Executar Localmente

1. Clone o repositório:
```
git clone https://github.com/ricaprof/coin-conversor.git
```

Instale as dependências:

    npm install

Inicie o servidor:

    npm run dev

Acesse:

http://localhost:3000
